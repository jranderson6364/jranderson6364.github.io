Driftbar privacy policy

Last updated: November 19, 2026.

Driftbar is a personal desktop app used only by its author.

What it accesses

With the user's consent, Driftbar requests read-only access to Google Calendar (calendar.readonly) and Google Tasks (tasks.readonly) to show the next calendar event and the most pressing task on the user's own screen.

How the data is used and stored

  • Event and task data is read on the user's own computer and shown only there. It is not sent to any server other than Google's APIs, and it is not shared, sold or used for advertising.
  • The sign-in token is stored in Windows Credential Manager on that computer. Event and task data is kept only in memory.
  • Driftbar never writes to the user's calendar or tasks.

Driftbar's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from Driftbar's menu ("Disconnect Google") or at myaccount.google.com/connections.
